# Proef PE 1
## Voorbereiding
Open deze repository met Visual studio code op je lokale laptop. Dit doe je door rechts bovenaan op de knop "code" te klikken en daarna via `git` de code te clonen op je toestel. 
Tijdens de opdracht mag je enkel gebruik maken van:
- Zelf gemaakte documentatie
- Het portaal van je Github repository
- Visual studio code als IDE met eventueel de YAML extentie van redhat.

Het gebruik van AI tools en AI plugins is niet toegestaan en wordt gezien als fraude. Toezichters zullen steekproefgewijs controleren of studenten enkel gebruik maken van het toegelaten materiaal. Het is niet toegestaan om extra extensies te installeren in de IDE.

## Opgave
Maak een nieuwe workflow aan met als naam `proef.yml`. Voorzie als trigger een handmatige start van de workflow.

Voeg een job toe met als naam "proefpe" die start op een Ubuntu virtuele machine.

Voeg een stap toe die "Hogeschool PXL" print en het bestand <studentennummer>.txt aanmaakt.

## Indienen
- Doe een commit met als bericht "einde examen". 
- Doe 3 runs van je workflow. 
- Steek je hand op en de docent controleert of de inzending succesvol is.

Veel succes!
